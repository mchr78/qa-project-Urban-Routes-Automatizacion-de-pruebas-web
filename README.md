Automatización de pruebas web | Urban Routes | QA Engineer Bootcamp - TripleTen 2026

## Descripción
Urban Routes es una aplicación web de transporte en la que los usuarios pueden solicitar un taxi. Mi objetivo fue automatizar pruebas funcionales para validar el flujo de solicitud de un taxi y comprobar que la aplicación se comportara como se espera.

## Diseño y Alcance de las Pruebas
- Desarrollé pruebas automatizadas con Python, Selenium WebDriver y Pytest.
- Automaticé escenarios de selección de tarifa, registro de teléfono y de tarjeta, mensaje al conductor, solicitud de servicios adicionales y cantidad de productos.
- Utilicé aserciones para verificar el comportamiento esperado.
- Gestioné el código con Git y GitHub, incluida la creación del repositorio.

## Herramientas y Técnicas:
- Python
- Selenium
- Pytest
- Git y GitHub
- PyCharm

## Resultado
Automatización del flujo principal de solicitud de taxi, lo que reduce la ejecución manual de pruebas funcionales repetitivas.
